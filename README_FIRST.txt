GENEVIEVE App™ FOOD V19.2 — START HERE
========================================

THIS IS THE REPAIRED ORIGINAL PINK V19 APP.
It has not been replaced with a different brown or redesigned interface.

USE ON YOUR WINDOWS COMPUTER
1. Extract the ZIP completely.
2. Open the extracted folder.
3. Double-click index.html.
4. The app should show Ready near the top.

DEPLOY WITH GITHUB + VERCEL
1. Put every file and folder from this package directly in the repository root.
2. index.html, app.js, styles.css, vercel.json and the api folder must be visible on the first repository page.
3. In Vercel choose Framework Preset: Other.
4. Leave Install Command, Build Command and Output Directory blank.
5. Deploy or redeploy.

NO API KEY IS REQUIRED.
NO PYTHON IS USED OR INCLUDED.
NO NPM BUILD IS REQUIRED.

PRODUCT LOOKUP REPAIR
- Vercel uses the same-origin /api/product function first.
- The app also tries two direct product-database routes.
- Previously loaded products are kept in a phone/browser cache.
- A readable barcode is never discarded just because the public database is slow.
- The photographed Cadbury Flake barcode 9300617433163 has a built-in label reference so that exact test packet loads even when the public database is unavailable.

IMPORTANT
Always compare the app result with the current physical packet. Product recipes and labels can change.
